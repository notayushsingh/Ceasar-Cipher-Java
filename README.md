# Caesar-Cipher-Java🔐
Caesar Cipher Encryption/Decryption.
This project is a simple implementation of the Caesar cipher encryption and decryption algorithm using Java.

## 📌About the Project ##
The Ceaser Cipher is a classical encryption technique in which each letter in a message is shifted by a specified number of positions in the alphabet.

## Example ##

•Original Message:Hello World

•Shift Value:3

•Encrypted Message:Khoor Zruog

The Program takes a message and a shift value from the user, then generates the encrypted text.

## 🔗Features#
•Accepts user input for the message.

•Allows the user to specify the shift value.

•Supports the uppercase and lowercase letters.

•Preserves spaces and non-alphabetic characters.

•Uses modulo arithmetic to handle arithmetic wraparound.

## 🛠️Technologies Used ##
•Java

•Java Scanner for user input

•Loops,Conditional Statements,Strings and characters

•ASCII Values and modulo arithmetic

## ▶️How to Run ##
1.Make sure the Java Development Kit(JDK) is installed.

2.Clone this Repository or download the source file.

3.Open a terminal in the directory Containing the Java File.

4.Compile and run the program:
java CaeserCipher.java

Replace CeaserCipher with your actual java class name if it differs.
